Get help with Perspectica

Before reporting a problem

  1. Confirm the article is a public HTTPS page and that article access was granted.
  2. Check provider readiness in Settings and retry only the failed phase or section.
  3. Open Diagnostics, select the run, and use Copy logs after reading the privacy warning.

Use the public issue tracker for ordinary bugs. Never place provider credentials, sessions, private article text, or unredacted security details in an issue.

Security reports

Use GitHub private vulnerability reporting for suspected vulnerabilities. Include the affected version, browser, reproduction steps, and impact without publishing a working exploit or secret material.
