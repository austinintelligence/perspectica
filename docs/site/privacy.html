Privacy

Perspectica privacy notice

Last updated: August 3, 2026

Perspectica is a self-contained browser extension. It does not operate an application server, sell personal data, serve advertising, or perform cross-site tracking.

What is processed

The local preview reads the active article's title, author, date, URL, links, publication metadata, and visible article text. Nothing is sent to an analysis provider until you select Analyze. A requested report sends bounded article context and research queries to the configured ChatGPT/search providers and may retrieve validated public HTTPS sources.

Credentials and retention

ChatGPT authorization occurs on OpenAI's page. Remembered refresh credentials and optional Exa keys are encrypted in the browser profile. Access tokens stay in session storage. Retained runs are encrypted, limited to ten runs or seven days, and capped at 25 MB. You can disconnect providers, clear retained runs, revoke site access, or uninstall at any time.

Permissions

Standard-site access is optional and requested with an explanation. Perspectica injects packaged extraction code on demand; it does not install a persistent page content script or load remote executable code.

Experimental connection

Login with ChatGPT uses a community device-flow integration and is not OpenAI's public identity product. Provider terms and privacy policies apply to information sent to them.
