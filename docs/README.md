# Perspectica documentation

The root [`README.md`](../README.md) is the reader-friendly overview. This directory contains the material for understanding the implementation and preparing a deployment.

## Start here

- [`architecture-v2.md`](architecture-v2.md) — the implemented analysis runtime;
- [`privacy.md`](privacy.md) — what the extension reads, stores, and sends;
- [`public-deployment.md`](public-deployment.md) — the Chrome Web Store and release checklist.

The [`plans/`](plans/) directory contains historical planning notes. Those notes explain how the project evolved; they are not the production architecture unless the current documents say so.

## Reader and developer paths

- If you are evaluating the extension, read [`privacy.md`](privacy.md) first.
- If you are developing the extension, read [`architecture-v2.md`](architecture-v2.md), then the package structure in the root README.
- If you are preparing a public build, read [`public-deployment.md`](public-deployment.md) and run the verification commands from the root README.
